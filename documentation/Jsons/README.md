### - ESP
Este apartado reúne las funciones del `namespace json`.\
Con ellas se crean estructuras JSON en memoria, se leen desde un texto o desde un archivo, se modifican y se consultan.\
Los nodos dinámicos se manejan de forma ligera y están cubiertos todos los tipos de datos nativos de JSON.\
Se da por hecho que quien lee conoce la especificación JSON.
