# 🧵 Thread Management
### - ESP
Este apartado abarca todo el conjunto de funciones de System Tools pertenecientes al `namespace thread`, encargadas de la creación y manipulación de ejecución de hilos en paralelo. Al ser una funcionalidad importante dentro del desarrollo de software de uso general, este módulo se incluye de forma nativa dentro de [**Default Functions**](../README.md) en la librería.\
Para la lectura de esta sección, se asume que el lector posee conocimientos previos sobre la ejecución de tareas en paralelo dentro del mismo programa, por lo que no se profundizará en dichos conceptos teóricos a fin de mantener la brevedad y concisión del documento.

A continuación se enlistan las funciones disponibles en este módulo:
* [`create`](create.md).
* [`join`](join.md).
* [`kill`](kill.md).
* [`yield`](yield.md).
