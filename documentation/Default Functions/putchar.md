# putchar
### - ESP
Firma:
```cpp
int putchar(int chr);
```
Parámetros:
* **Chr**: Carácter que se desea imprimir en la terminal.

Retorno:\
Número entero que representa el carácter impreso, o `-1` si hubo un problema al intentar imprimirlo.

\
Comportamiento:\
Imprime el carácter indicado en la terminal.\
Adaptación de `putchar` de `<stdio.h>` (véase [Default Functions](README.md)).

### - ENG
Signature:
```cpp
int putchar(int chr);
```
Parameters:
* **Chr**: Character to be printed to the terminal.

Return:\
An integer representing the character printed, or `-1` if there was a problem trying to print it.

\
Behavior:\
It prints the specified character to the terminal.\
Adaptation of `putchar` from `<stdio.h>` (see [Default Functions](README.md)).
