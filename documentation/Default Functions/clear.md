# clear
### - ESP
Firma:
```cpp
FORCEINLINE void clear();
```
Comportamiento:\
Abstracción de la llamada `system("clear")` o `system("cls")` según la plataforma.\
Unifica en una sola invocación el concepto de limpiar todo el texto de la terminal.
